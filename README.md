# AUTOHIAM: Automated Robotic System for Hydrogel Infusion Additive Manufacturing

AUTOHIAM is an affordable and flexible vision-based robotic system that automates Hydrogel Infusion Additive
Manufacturing.

[**Paper**](https://epfl-alchemy.github.io/autohiam/) | [**Project**](https://epfl-alchemy.github.io/autohiam/) | 
[**Video**](https://epfl-alchemy.github.io/autohiam/)

## Introduction

AUTOHIAM is an open-source robotic platform that automates the entire HIAM workflow. It enables chemists to run
multi-cycle, multi-sample experiments 24/7 without programming. AUTOHIAM uses vision-based pose estimation with ArUco
markers and cuRobo-based GPU-accelerated motion planning to perform collision-free sample transfer. It supports liquid
handling via low-cost peristaltic pumps, robot-assisted drying, and flexible obstacle-aware planning. The system
interacts with chemists through natural language to configure experiments and can be monitored remotely. Tested on Gen2
metal-ceramic fabrication, AUTOHIAM achieves sample quality comparable to manual execution while improving safety,
scalability, and throughput.
